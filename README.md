# Gestão Financeira para Pequenos Empreendedores

Projeto desenvolvido para a disciplina Atividade Extensionista II do curso de Ciência de Dados da UNINTER.

## Objetivo
Desenvolver uma ferramenta acessível para auxiliar pequenos empreendedores no controle de vendas, despesas, estoque e lucro.

## Tecnologias
- Microsoft Excel
- Python
- Pandas
- Matplotlib
- Openpyxl

## Como executar
1. Instale Python.
2. Instale as bibliotecas: `python -m pip install pandas matplotlib openpyxl`.
3. Mantenha a planilha e o código na mesma pasta.
4. Execute: `python analise_financeira.py`.
5. Consulte os relatórios gerados na pasta resultados.

## Situação do projeto
Ferramenta em fase de testes e validação com a comunidade.
